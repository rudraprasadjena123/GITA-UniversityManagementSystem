# 🎓 University Management System

A desktop-based **University Management System** developed using Java, Swing, JDBC, and MySQL. This application helps manage student records efficiently through a simple and user-friendly interface.

## ✨ Features

- 👨‍🎓 Student Management
- ➕ Add Student Records
- ✏️ Update Student Information
- 🗑️ Delete Student Records
- 🔍 Search Student Records
- 📋 View Student Details
- 🗄️ MySQL Database Integration
- 🔐 Database Connectivity using JDBC
- 🖥️ Interactive Java Swing Interface
- ♻️ CRUD Operations

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| ☕ Java | Core application development |
| 🎨 Java Swing | Desktop GUI |
| 🧩 OOP | Application architecture |
| 🔗 JDBC | Database connectivity |
| 🗄️ MySQL | Data storage |
| 🌐 HTML | UI-related content |
| 🎨 CSS | Styling |
| ⚡ JavaScript | Interactive elements |
